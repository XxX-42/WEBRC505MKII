## Remaining non-fabricated controls

Unsupported MODE rows require the undocumented alternate algorithm semantics. Factory AUTO RIFF PHRASE, PATTERN SLICER PATTERN and BEAT SCATTER TYPE require the actual factory content. Physical VOCODER carrier input routing and CARRIER THRU are not substituted with oscillator audio. Read each CSV note for exact scope.

Bank-level switching/assignments, full hardware MEMORY archive compatibility and complete MIDI ASSIGN are not covered by this 267-row per-algorithm claim. Hardware sound parity, strict real-time guarantees and user-machine deployment remain unverified.

See `api-contract.md` for real setters, native acknowledgement, reset/replacement, units and legacy compatibility.
