# Classic control coverage — 2026-11-14

This is a map of the current implementation and evidence, not a claim of full physical-device parity. “Fixed” describes this change; “retained” describes an existing path that remains in use. Test paths identify coverage, not a statement that every suite passed in a particular run. See the separate run status for actual results. No physical RC-505mkII or real LED photometry was used for this review.

Official sources: [Owner's Manual eng04](https://static.roland.com/assets/media/pdf/RC-505mk2_eng04_W.pdf) (page numbers below are printed/PDF pages) and [Parameter Guide eng04](https://static.roland.com/assets/media/pdf/RC-505mk2_Parameter_eng04_W.pdf). The [LCD layout matrix](../lcd-layout-matrix-20261114.md) records source version, page coverage and the distinction between official evidence, user-selected four-column layout and engineering decisions.
