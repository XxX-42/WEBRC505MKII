# RC-505 software parity progress — 2026-11-07

Base: `b415596` (enlarged Classic recording symbol).

## Confirmed fixes

- Native synchronized playback now accepts rounded cumulative measure boundaries.
  The previous frontend required an integral frame offset before rounding and
  rejected valid 99 BPM / 6/8 recordings. Regression fixtures cover 48 kHz and
  44.1 kHz, with one-frame-short and one-frame-long PCM still rejected.
- Browser Rhythm chooses an ordinary start origin on the audio thread, retaining
  the existing engineering lead of 50 ms from message handling. Its phase ACK
  describes that actual origin. Explicit-origin protocol messages remain strict.
  Stop/restart during asynchronous module loading invalidates stale starts; a
  missed origin stops Rhythm and exposes a retryable error.

## Tech controls and regression navigation

Tech FX sections now retain their content width and the whole Tech surface can
scroll. Previously, flex compression moved FX A into unreachable negative
horizontal space; enabling vertical scrolling alone did not fix it. The
unchanged ROLL/FREEZE tests reproduced the failure before the content-width fix
and passed 2/2 afterwards using ordinary clicks and the original time limit.

Regression navigation now opens private track FX through Enhanced tools and
finds rhythm fields on their actual LCD pages. The integrated six-file E2E run
passed 21/21, one worker, zero retries, original 30-second per-test limit. It
covers the complete app spec and private AUTO RIFF, HRM MANUAL, OCTAVE, PITCH
BEND and ROBOT audio routing, controls, persistence and reload. This is a scoped
result, not a new full-suite E2E claim.

## Native batch integration gate

Native atomic ALL transport remains in its isolated development worktree.
Cross-review found incomplete durable-receipt handoff, premature per-member
fence release, and scheduled PLAY cursor publication. Target-frame preflight
also needs to account for ONE SHOT ending between block start and execution.
No complete ALL transport acceptance is claimed.

The remaining full-suite E2E failures have not all been revalidated yet.

These results are software evidence. They do not establish physical RC-505
timing, sound equivalence, LED photometry, or a complete hardware 1:1 result.
