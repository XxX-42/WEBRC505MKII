- The earlier roughly 40 ms P99 five-track KeepPitch number came from a VM cross-realm diagnostic artifact and is not a valid real-time performance measurement. The latest same-realm Node/V8 benchmark is linked from [the Worklet evidence bundle](validation/20261009/worklet-bench-20261009T055725581Z-53f516c7/manifest.json): five-track 8-layer KeepPitch P99/max was 2.081/4.571 ms with a 14.906 ms startup block and one startup miss, 11 warmup misses per 2,000 and 9 measured misses per 3,000; 8-layer-plus-active-overdub was 2.341/8.651 ms with a 6.876 ms startup block and one startup miss, 5 warmup misses and 13 measured misses. Normal five-track 103-segment-per-track playback had P99 0.129 ms, max 4.712 ms and 3 measured misses per 3,000. These synthetic Node measurements include long-tail deadline overruns and startup cost; they are not Chromium callback timings or hardware XRUNs. Strict real-time KeepPitch qualification remains outstanding.
