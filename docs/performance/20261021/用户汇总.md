## 2. 主要热点

1. Native PREAMP 的帧参数推导与重复 ADAA 原函数计算。
2. Browser PREAMP / DIST 的重复原函数、偏置与不变参数计算。
3. Browser PHASER、MOD DELAY、TAPE ECHO 高频 clamp 调用。
4. Browser FDN Reverb 插值、混音及剩余逐样本数学计算。
5. Native 剩余 PREAMP 非线性运算、ROBOT 音高检测和 Signalsmith 频谱运算。

这些来自实际 CPU profile，但 Browser profile 是 Node 执行生产 DSP bundle，不是浏览器音频线程。

## 3. 实际修改

保留原精度、滤波、过采样和音频算法，仅加入精确缓存、严格 +0 恒等快路、ABI 保持的分组参数刷新、旁路整块复制和语义等价的 clamp 快路。参数变化、模型切换、微小差分、静音恢复及 reset 都有失效规则和回归覆盖。没有降低音质模式，没有改写用户 UI。

继续进行了多轮证伪：Native 环形缓冲、强制内联、整块 FX 分派、LTO，以及 Browser Reverb 插值/不变乘法候选，没有稳定达到收益门槛的全部撤回。

## 6. 实时预算与长稳

最终源码 Native 216 场景的独立性能门禁为 170 PASS / 46 FAIL，额外 6 个场景均 FAIL；216 格记录 1628 次 CPU 超预算，最坏 p99 为整帧预算的 628.76%，全部保留。旧矩阵的 150/66 不与新固定 CPU 环境混算收益。CPU 超预算次数不是硬件 XRUN。普通 C++ new/new[] 计数不覆盖所有 malloc / aligned allocation。

最终源码真实墙钟 Native 10 分钟检查点已通过：600.003 秒、225001 callbacks、6000 命令、750 FX 切换，队列拒绝、状态错误、输出非有限值和所拦截 new/new[] 均为 0。相同进程已完成真实 30 分钟终态：2026-10-21 13:23:43.900997 至 13:53:43.911419 UTC，675001 callbacks、18000 命令、2250 FX 切换，以上功能错误均为 0。稳定后 RSS 增加 100 KiB，不能据此宣称全应用无泄漏；保留 5336 次 CPU 超预算及最大 42.2175 ms，不称硬件 XRUN。旧源码的 30 分钟结果独立归档，不作为当前源码长稳证据。长稳初段并行执行短功能检查，因此它是稳定性门禁，不冒充隔离性能 A/B。

实际 Browser AudioWorklet callback、GC、UI long task、真实 IPC 和硬件 XRUN 均为 NOT_VERIFIED / null，不填写假零。
