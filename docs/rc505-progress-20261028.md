# RC-505 软件集成进度（2026-10-28）

当前开发基线为 `main` 的 `e33a468`；本页描述 `codex/rc505-parity-integration-20261028` 上的工作进度，不代表 RC-505mkII 整体 1:1 已验收。本地实体设备枚举未发现 RC-505，未测实体环回、音色或 LED 光度。

- Browser AUTO REC 已接入共享采集、Classic LCD 与 Memory；SENS 到阈值的映射是软件近似，官方未公布具体检测算法。见 [Browser AutoRec](BROWSER_AUTO_REC.md)。
- Browser BOUNCE 已接入独立来源轨、目标轨、立体声录音和叠录，并接入 Classic LCD 与 Memory。活动录音期间拒绝修改路由；源信号当前取自轨道 FX 前，硬件复制点仍未验证。见 [Browser Bounce](BROWSER_BOUNCE.md)。
- Native REC ACTION 已支持 REC→PLAY／DUB、预算内独立历史、callback ACK 及 Memory；Native 录音量化仍明确不可用。Native 源码在隔离工作树通过标准 CTest 46/46 和模拟 CTest 13/13；不能据此声称真实 WASAPI 或实体 RC-505 已验收。
- Browser REVERSE 开启时不再进入叠录；回退到正向后可继续叠录。旧反向叠录测试已按官方约束调整，并增加专门的行为测试。
- 之前 E2E 中 START AUDIO 缺失的 21 项中，已定位到测试 AudioContext mock 缺少通道分流与分析器；修复后的独立 E2E 为 104 通过、8 个 Native 仿真未配置而跳过、0 失败。此数字属于修复分支基线，不是全部集成后的最终 E2E。

集成专项：Browser AutoRec、捕获与 Memory 等 61/61 单测及 4/4 Chromium 音频测试通过；Classic LCD Bounce 选来源轨并录入目标轨的真实 Chromium 测试通过。Browser／Native REC 及控制层整合专项 111/111 通过。完整单测第一次为 2570/2573；三项失败修正后相关四个测试文件 92/92 通过，完整套件仍待重跑。计数不得相加作为完整通过数。

BOUNCE 音轨源 FX 插入点、电平及限幅仍是硬件未知项。Native BOUNCE、Browser 1SHOT 和 DUB MODE 正在独立分支开发，尚未包含在本快照；真实硬件、物理延迟、长稳 XRUN、音色 Golden Master 与光度仍未验收。
