# OCTAVE mode adapter candidate

This standalone adapter implements the reviewed OCTAVE selector choices `-1OCT`, `-2OCT`, and `-1OCT&-2OCT` from printed page 39 of the official UI contract snapshot in `reference/dsp/spec/official_fx_ui_contracts.json`. The -1 voice runs one existing -12 semitone phase-vocoder stage; -2 cascades two independent -12 stages; dual mode mixes both aligned voices. This is a clean-room reconstruction, not a Roland sound model.

The branches keep left and right independent and run continuously so a mode event can switch at a sample offset without warming a cold path. The -1 voice is delayed by one extra window and the dry path by two windows to align all mixed paths. At 48 kHz with a 2048-frame window and 256-frame hop, `fixedMixedPathSamples` is 4096 frames (85.33 ms). The cold -2 impulse first became nonzero at frame 514; a warmed impulse against an identical warm-control render first differed at frame 940. Those onset measurements are separate from the fixed alignment delay and from host end-to-end latency.

The fresh MSVC Release fixture measured -1 tone projections of 0.3447/0.2841 for left/right 440/330 Hz outputs from 880/660 Hz inputs, -2 projections of 0.0795/0.1900 at 220/165 Hz, and dual projections of 0.1724/0.0397/0.1421/0.0950 for left 440/220 and right 330/165 Hz. A 500 ms gated -2 note occupied 528 ms at the test's RMS threshold. The result records bit-identical 64/128/256-frame partitions, no right-channel leakage in a left-only dual fixture, a 0.0439 maximum post-event difference after a mode event at sample 37 with zero pre-event difference, and zero callback allocations/frees. These are bounded standalone functional measurements, not final sound-quality qualification.

The underlying phase vocoder uses spectral-bin interpolation and has no transient phase locking; cascading can compound spectral smear and startup behavior. No final transient/audio quality, real-time deadline, host graph, native/WASM parity, or device-equivalence gate is claimed. The conservative estimate for this fixture is 1,630,184 bytes. In no-exception builds, an allocator failure is not recoverable within the active process.
