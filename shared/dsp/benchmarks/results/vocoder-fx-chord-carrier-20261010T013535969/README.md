# VOCODER20 external carrier and OSC VOC(M) standalone verification

This immutable closure contains the standalone C++17 implementation and test harness for catalog ordinals 20 and 21. VOCODER20 requires a caller-supplied stereo carrier and never fabricates an oscillator; `processBlockWithCarrier` rejects a null carrier and accepts only the VOCODER kind. The host must resolve MIC1/MIC2/INST1-L/R/INST2-L/R/TRACK1–5 and report an unavailable selected route instead of substituting a tone. OSC VOC(M) accepts bounded same-frame MIDI chords, preflights fixed voice-retirement capacity transactionally, and exposes five distinct clean-room oscillator waveforms (Saw, Vintage/Sine, Detune, Square, Rect pulse pair). Waveform automation uses a 64-sample equal-power transition.

Run `build_release.cmd` with the pinned MSVC 2019 Build Tools path. The Release suite covers chord creation/replacement and capacity rejection, 64-event bursts at 1/64/128-frame callbacks, zero-carrier silence, carrier replacement, stereo independence, all waveform PCM differences, sample-accurate waveform change, event transactionality, no callback allocation/free, and partition invariance. This is standalone-source evidence only; it does not qualify registry adapters, live host routing, browser graph integration, hardware, or final Gate quality.
